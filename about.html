About CodeRa

Last updated: October 2026 · CodeRa – Chrome extension for extracting code from video

CodeRa is a free Chrome extension that extracts formatted code from YouTube, Udemy, Coursera videos and screenshots using AI vision, preserving indentation.

Who built it

Built by Anton Zakharenka — a developer tired of retyping tutorial code. Not affiliated with Anthropic.

What it does

  • Capture a video frame (Alt+C or floating button) without leaving the lesson
  • Extract as code, plain text, or get an explanation
  • Collect a whole lesson while you watch, then export timeline + HTML/CSS/JS
  • Keep snippets in a local library; export to Obsidian, Anki, Notion, or GitLab Snippets
