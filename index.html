// how it works

Three steps. Under 10 seconds.

1

Click CodeRa

Open the extension on any page. Pick your mode, text, code, or understand.

2

Capture

Hit Capture Video Frame on YouTube or Udemy. Or drag over any code. Or upload a screenshot.

3

Paste anywhere

Code lands in your clipboard. Review in the result panel. Ctrl+V into your editor.

// three AI modes

One click. Three ways to use it.

📄
Default mode

Plain text

Extracts everything visible, subtitles, slide text, captions, UI labels. Exactly as shown, nothing rewritten.

💻
Extract as code

Code extraction

CodeRa finds the code, preserves indentation, brackets, and comments. Open your editor and run it, no cleanup.

🧠
Understand code

Learn & trace

CodeRa explains what the snippet does, traces execution line by line, shows expected output. Learn the logic.

// product features

Built for the whole learning loop

Capture once, keep the snippet, ask follow-ups, export to your notes — without reopening the popup every time.

1-click capture

Hotkey + floating button

Press Alt+C or tap the floating CodeRa button on the player. Frame capture without opening the popup.

local library

Snippet library

Sidebar filters by YouTube / Udemy / source type, search, timestamps, and one-click publish to GitLab Snippets.

exports

Notion, Obsidian, Anki, GitLab

Export a snippet as Obsidian Markdown, Notion-ready Markdown, Anki cards, or push straight to GitLab Snippets.

trust

Bracket / syntax check

After code extraction, CodeRa checks brackets and flags likely OCR mistakes before you paste into your editor.

understand

Ask about the snippet

Follow-up chat on the result panel: ask anything, or one-click “explain like a beginner” (including Russian).

translate

Language conversion

Convert a captured snippet to JavaScript, Python, Go, Java, Rust, or TypeScript in one click.

anywhere

Not only course videos

Select Area works on Zoom/Meet shares, PDFs, slides, Twitch, Slack/Discord screenshots — any code on screen.

editor

VS Code / Cursor bridge

One click copies a CodeRa-marked snippet. In VS Code/Cursor run CodeRa: Insert Snippet (companion extension) to drop it into the open file.

lectures

Collect whole lesson

Start collection and keep watching — CodeRa grabs frames as you play (and when you scrub), with no blinking and no forced rewind. Finish to get a timestamped timeline plus assembled files like index.html, styles.css, script.js.

UX

Corner toasts

Confirms, progress, and errors appear as small corner notifications — they never block the video or steal focus from the lesson.

// faq

Quick answers

Is it really free?
Yes, completely free during early access. All features unlocked. No account, no credit card.
Is it safe to use at work?
Yes. Screenshots are processed and immediately discarded, nothing stored on any server. Same privacy as typing into Claude directly. Safe for proprietary code.
Does it work on YouTube and Udemy?
Yes. Click Capture Video Frame on any course site, grabs the current frame while the video keeps playing. Works on YouTube, Udemy, Coursera, Skillshare, and any embedded player.
What's the difference between the three modes?
Plain text, extracts everything as-is (subtitles, slides). Extract as code, IDE-ready formatted source. Understand code, CodeRa explains the logic and shows expected output, built for learning.
Who built CodeRa?
Built by Anton Zakharenka, a developer who got tired of retyping code from tutorials. Not developed by Anthropic.
