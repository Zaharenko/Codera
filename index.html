// faq

Questions that matter

Is it safe to use at work?
No CodeRa cloud library — snippets you keep stay in your browser. Extraction goes over HTTPS through the CodeRa relay to Anthropic’s Claude API. Under Anthropic’s commercial terms, API inputs are not used to train models by default. Prefer Select Area to send only the code region. If your workplace forbids third-party AI APIs, don’t use CodeRa on that code. Full detail: Privacy Policy.
Where does it work?
YouTube, Udemy, Coursera, Skillshare, and most embedded HTML5 players — in Chrome, Edge, Brave, and Opera.
Is it free?
Yes during early access: all features unlocked, no account, no credit card. Fair-use limits may apply. Pricing will be published before any charges begin.
