// how it works

How it works

1

Click CodeRa

Press Alt+C, use the floating button on the player, or open the extension and pick a mode.

2

Capture

Grab the current video frame, drag over any code on the page, or upload a screenshot.

3

Paste anywhere

The result is copied to your clipboard and shown in the result panel. Press Ctrl+V in your editor.

// product features

Collect a whole lesson into project files (1.2.0, rolling out)

One-off OCR gives you one frame. A lecture builds code over many minutes. Start collection, keep watching, and CodeRa gathers frames as you play and when you scrub, without blinking the video or forcing a rewind. When you finish, you get a timestamped timeline and assembled files such as index.html, styles.css and script.js.

Many frames are sent for processing while collection is on. You can stop at any time. See what is sent.

Everything else in the learning loop (1.2.0, rolling out)

library

Snippet library

Search, filter by source, timestamps. Stored in your browser.

exports

Exports

Obsidian, Notion (Markdown), Anki cards and GitLab Snippets, only when you press export.

trust

Bracket check

Flags likely OCR mistakes before you paste.

follow-up

Questions & language conversion

clipboard

UX

// privacy

Your privacy, in plain words

  • CodeRa does not keep your screenshots and has no cloud library. Your snippet library stays in your browser.
  • When you extract, the image goes through a CodeRa relay to Anthropic's Claude API, which returns the text.
  • Anthropic's commercial terms say customer content is not used to train models by default. Retention is set by Anthropic.
  • Crop to the code, and do not capture secrets. If your employer restricts sending code to AI services, do not use CodeRa on that code.

// faq

Frequently asked questions

Is CodeRa really free?
Yes, during early access all features are unlocked, with no account and no credit card. Fair-use limits may apply. Pricing will be published before any charges begin.
Is it safe to use at work?
CodeRa does not keep your screenshots or build a cloud library. When you extract, the image is sent through a CodeRa relay to Anthropic's API for processing. If your employer restricts sending code to third-party AI services, do not use CodeRa on that code. Crop to the code region and avoid capturing secrets. Details: Privacy.
Does it work on YouTube and Udemy?
Yes. CodeRa grabs the current frame while the video keeps playing. It works on YouTube, Udemy, Coursera, Skillshare and most embedded players.
What is the difference between the three modes?
Plain text copies everything as shown. Extract as code returns editor-ready source. Understand code explains the logic and shows the expected output.
Is copying code from paid courses legal?
You are responsible for following each platform's terms and copyright law. CodeRa is a personal productivity tool for capturing what is already on your screen. Use extracts for your own learning and do not redistribute course materials. See the Terms.
What are the free-plan limits?
During early access, core features are unlocked without an account. Fair-use limits may apply, and exact quotas will be published when paid plans launch.
Does it work in Edge, Brave and Opera? What about Firefox?
Yes on Chromium browsers through the Chrome Web Store. Firefox is not supported yet. See the roadmap.
How accurate is it?
Accuracy depends on resolution, contrast, fonts and motion blur. Code mode is built to preserve indentation, and the bracket check catches some recognition mistakes. DRM-protected or blacked-out frames cannot be read. A public comparison with Lens and others is on the roadmap.
What happens if a frame is black?
Some players block frame capture. If pixels are not available, no OCR tool can read the code. Use the instructor's downloadable resources or GitHub repository instead.
Who built CodeRa?
Anton Zakharenka, an independent developer who got tired of retyping code from tutorials. CodeRa is not affiliated with Anthropic. More on the About page.
