// new · whole lesson

One frame is cute. A lecture is a project.

Tutorials don’t write one function and stop. They grow HTML, then CSS, then JS over twenty minutes. CodeRa can ride along — collect frames while you watch, then hand you a timeline and files you can open.

// the rest of the toolkit

Not just a clipboard trick

Same extension after the paste: library, exports, follow-ups — the boring-but-useful stuff you actually keep using.

capture

Frame, area, or upload

Alt+C / floating button for video. Select Area for slides and docs. Upload a PNG/JPEG when the code is already a screenshot.

library

Local snippet library

Search, filter by source and language, jump back to the timestamp. Stored in your browser — not a CodeRa cloud folder.

exports

Obsidian · Notion · Anki · GitLab

Export only when you press the button. GitLab Snippets with a token that stays local.

follow-up

Ask & convert

Ask about a snippet, or convert it to JS, Python, Go, Java, Rust, or TypeScript without leaving the flow.

bracket check

Catch OCR oops before paste

Flags likely missing braces and similar recognition mistakes so you don’t debug garbage for ten minutes.

controls

Floating buttons you can hide

CodeRa + Lesson sit on the player when you want them. Toggle them off in the popup if you prefer Alt+C only.

// faq

Questions that matter

Is it safe to use at work?
No CodeRa cloud library — snippets you keep stay in your browser. Extraction goes over HTTPS through the CodeRa relay to Anthropic’s Claude API. Under Anthropic’s commercial terms, API inputs are not used to train models by default. Prefer Select Area to send only the code region. If your workplace forbids third-party AI APIs, don’t use CodeRa on that code. Full detail: Privacy Policy.
Where does it work?
YouTube, Udemy, Coursera, Skillshare, and most embedded HTML5 players — in Chrome, Edge, Brave, and Opera.
Is it free?
Yes during early access: all features unlocked, no account, no credit card. Fair-use limits may apply. Pricing will be published before any charges begin.
What’s the whole-lesson feature?
Instead of one Alt+C, you start collection and keep watching. CodeRa gathers frames along the way and assembles a timeline plus project-style files. Shipping in 1.2.0 (rolling out). Frames still use the HTTPS extract relay — see Privacy.
