CodeRa roadmap

Updated 8 Oct 2026 · No invented ship dates. Priorities move with your feedback.

Available now (Store version 1.1.0)

  • Video frame capture with Alt+C and the floating button, Select Area, image upload
  • Three modes: plain text, extract as code, understand
  • Bracket and syntax check after extraction

Rolling out (version 1.2.0)

  • Collect whole lesson into a timeline and project-style files
  • Local snippet library with search and filters
  • Exports to Obsidian, Notion Markdown, Anki and GitLab Snippets
  • Follow-up questions and language conversion
  • Marked clipboard copy for pasting into editors

In development

  • VS Code and Cursor insert command (status)
  • Public accuracy comparison with Lens and Live Text, with method and examples
  • Reliability and fair-use improvements
  • Crop and compress before upload to send less data

Later ideas

  • Free web version of Image to Code, with no install
  • Firefox and Edge Add-ons listings
  • Russian guide hub
  • Instructor checklist for capture-friendly lessons
  • More export targets
