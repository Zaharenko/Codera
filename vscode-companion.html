VS Code / Cursor companion

Last updated: October 8, 2026

CodeRa copies a marked snippet to your clipboard; the companion command inserts it into the open editor file. No cloud sync — the bridge stays on your machine.

How it works

  1. Extract code with the CodeRa Chrome extension.
  2. Use the result action that copies the CodeRa-marked payload for the editor.
  3. In VS Code or Cursor, run the command palette → CodeRa: Insert Snippet.

Status

The clipboard bridge ships with CodeRa. The companion extension for VS Code/Cursor is distributed with the product updates listed on the changelog. Marketplace listing link will be added here when published.
