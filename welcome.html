Welcome to CodeRa 👋

One thing first, takes 5 seconds, and it's the difference between using CodeRa daily and forgetting it exists tomorrow.

// do this first

Pin CodeRa to your toolbar

Chrome hides new extensions inside the puzzle-piece menu. Pin CodeRa so it's always one click away while you're watching a tutorial.

youtube.com/watch?v=...
① click the puzzle icon
  • 1 Click the puzzle-piece icon in Chrome's toolbar (top right).
  • 2 Find CodeRa in the list.
  • 3 Click the pin icon next to it. Done — CodeRa now lives in your toolbar.
// three ways to use it

Pick a mode whenever you click CodeRa

📄

Plain text

Grabs everything visible, subtitles, slides, captions, exactly as shown.

💻

Extract as code

Finds the code, keeps indentation and comments, ready to paste into your editor.

🧠

Understand code

Explains the snippet line by line and shows the expected output.

// new power tools

Worth knowing on day one

fast capture

Alt+C + floating button

Grab a video frame without opening the popup. One keystroke while the tutorial plays.

whole lesson

Collect whole lesson

Hit Lesson on the player and keep watching. Frames are sampled as you play (and when you scrub) — no blinking, no forced rewind. Press Assemble for a timeline plus HTML/CSS/JS files.

library

Snippet library

Filter by YouTube / Udemy / capture type, search locally, remove duplicates, export to Obsidian, Anki, Notion, or GitLab Snippets.

editor

Ask, convert, send to Cursor

Chat about a snippet, translate languages, or copy a marked payload for VS Code / Cursor insert.

UX

Corner toasts

Progress and confirms stay in the corner so the tutorial video is never covered by a full-screen dialog.
