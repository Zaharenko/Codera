// three AI modes

Same capture — three different results

Pick one mode in the popup — your choice is remembered. Raw text, paste-ready code, or an explanation of what the code does.

Plain text

📄 Plain text

Claude reads everything visible and returns it exactly as shown — no interpretation, no reformatting. Use this for subtitles, slides, and UI text.

  • Video subtitles and captions, as the video plays
  • Conference slide bullet points and titles
  • UI labels, error messages, chat text
  • Mixed content — prose and code returned as raw characters
Extract as code

💻 Code extraction

Claude identifies programming code and returns clean, paste-ready source. Indentation, comments, and brackets preserved exactly. Open your editor and run it.

  • IDE screenshots and terminal output
  • Code shown in YouTube and Udemy tutorials
  • Config files, JSON, SQL, shell scripts
  • Multiple snippets separated with blank lines
Understand code

🧠 Learn & trace

Built for following courses: Claude explains what the snippet does, traces execution step by step, and shows expected output. Understand before you paste.

  • Follow coding workshops without getting lost
  • See what a function returns before you type it
  • Trace loops and variable changes line by line
  • Algorithm walkthroughs from slides or video frames

Your choice is remembered between sessions. Switch modes anytime from the popup — no settings page, no config files.

// faq

Common questions

Everything you need to know before installing.

How is CodeRa different from Apple Live Text or Google Lens?

System OCR reads characters blindly — it destroys code indentation and confuses {, }, and =>. CodeRa uses Claude Vision to understand code structure and outputs paste-ready source in code mode, or full-page text in plain text mode.

Why not just upload screenshots to ChatGPT?

That takes 5+ steps: screenshot → save → open tab → upload → write a prompt → copy result. CodeRa cuts it to one click — prompts are built in, result is auto-copied, you never leave the page you're on.

Is it safe to use at work?

Yes. Your screenshots are processed by the Claude Vision API and immediately discarded — nothing is stored on any server. No account, no screenshot library, no logs on our side. Same privacy guarantee as typing a prompt into Claude directly. Safe for proprietary and corporate codebases.

What's the difference between text, code, and understand modes?

Select Plain text for subtitles and slides. Choose Extract as code for paste-ready source, or Understand code for a step-by-step explanation with expected output.

Does it work on YouTube and course sites?

Yes. Click Capture Video Frame on YouTube, Udemy, Coursera, Skillshare, and any other educational platform — grabs the current frame while the video keeps playing. No pause, no screen recording, no file saving.

Is CodeRa free?

Yes — CodeRa is completely free during early access. All features unlocked: video capture, all three AI modes, unlimited extractions. No credit card, no account.

Who built CodeRa?

CodeRa is built by Anton Zakharenka — a developer who got tired of retyping code from tutorials. It uses Claude Vision AI for extraction and is not developed by Anthropic.
