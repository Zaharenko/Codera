Распознать код со скриншота

Коротко: загрузите PNG/JPEG в CodeRa → «Код», либо выделите область на странице. Обычный OCR часто ломает отступы — режим кода как раз для этого.

Установить CodeRa бесплатно

В CodeRa

  1. Откройте popup → Upload Image или Select Area.
  2. Режим Extract as code / «Код».
  3. Проверьте результат и вставьте.

Типичные ошибки OCR

  • Плоские отступы
  • Склейка номеров строк с кодом
  • Путаница символов в лигатурах
