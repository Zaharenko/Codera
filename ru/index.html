CodeRa — расширение для Chrome, которое достаёт оформленный код из видеоуроков и скриншотов в один клик. Отступы сохраняются, регистрация не нужна.

Установить из Chrome Web Store

Работает в Chrome, Edge, Brave и Opera · Без аккаунта · Бесплатно в раннем доступе

Транскрипт видео

На YouTube идёт урок. Зритель нажимает Alt+C. CodeRa захватывает кадр, распознаёт код с отступами и копирует в буфер. Вставка в VS Code — готово.

// как это работает

Как это работает

  1. Нажмите CodeRa. Alt+C, плавающая кнопка на плеере или значок расширения.
  2. Захватите. Текущий кадр видео, область на странице или загруженный скриншот.
  3. Вставьте. Результат уже в буфере обмена и в панели результата. Нажмите Ctrl+V в редакторе.

// режимы

Три режима

  • Текст. Всё, что видно на экране, как есть: субтитры, слайды, подписи интерфейса.
  • Код. CodeRa находит код и сохраняет отступы, скобки и комментарии, чтобы его можно было запускать без правок.
  • Объяснение. CodeRa объясняет, что делает фрагмент, разбирает его по строкам и показывает ожидаемый результат.

Чем отличается от Google Lens и ChatGPT

  • Google Lens и системное распознавание часто теряют отступы и путают символы вроде { } => ;. Режим кода в CodeRa создан, чтобы сохранять структуру. Подробнее: CodeRa vs Google Lens.
  • ChatGPT и Claude.ai справляются, но нужно пять и больше шагов. В CodeRa это один клик.
  • Нужен полностью локальный вариант? Смотрите альтернативы без отправки в облако.

// приватность

Как устроен поток данных

  • Без облачной библиотеки CodeRa. Сниппеты остаются в хранилище браузера.
  • HTTPS-релей. Кадр идёт на релей CodeRa → API Claude (Anthropic) → текст обратно.
  • Обучение моделей. По коммерческим условиям Anthropic входные данные API по умолчанию не используются для обучения.
  • Вы решаете, что отправлять. Удобнее Select Area — только область с кодом. Полный разбор: Политика конфиденциальности. Нужен полностью офлайн OCR — альтернативы.

Частые вопросы

Это бесплатно?

Да. CodeRa уже в Chrome Web Store — waitlist не нужен для установки. В раннем доступе все функции открыты без аккаунта и карты. Могут быть лимиты fair use; цены объявим до любых списаний. Сбор урока (1.2.0) выкатывается: если в Store ещё 1.1.0, обновите расширение, когда появится новая сборка.

Безопасно ли использовать на работе?

Облачной библиотеки скриншотов нет. Распознавание идёт через HTTPS-релей в API Anthropic (см. Приватность). Лучше обрезать до кода. Если политика компании запрещает внешние ИИ API — используйте офлайн-инструмент.

Работает ли на YouTube и Udemy?

Да. CodeRa захватывает текущий кадр, пока видео продолжает играть. Подходит для YouTube, Udemy, Coursera, Skillshare и большинства встроенных плееров.

Законно ли копировать код из платных курсов?

Вы сами отвечаете за соблюдение правил платформы и закона об авторском праве. CodeRa — инструмент для личного использования. Используйте результат для собственного обучения и не распространяйте материалы курса. См. Условия использования.

Что если кадр чёрный?

Некоторые плееры блокируют захват. Если пикселей нет, ни один инструмент распознавания не прочитает код. Ищите файлы автора курса или его репозиторий на GitHub.

Работает ли в Edge, Brave и Opera? А в Firefox?

Да, во всех браузерах на Chromium через Chrome Web Store. Firefox пока не поддерживается, см. дорожную карту.

Насколько точно распознаёт?

Точность зависит от разрешения, контраста, шрифта и размытия. Режим кода рассчитан на сохранение отступов, а проверка скобок ловит часть ошибок. Публичное сравнение с Lens есть в дорожной карте.
