CodeRa — расширение Chrome, которое извлекает оформленный код с обучающих видео и скриншотов в 1 клик. Отступы сохраняются, регистрация не нужна.

Установить из Chrome Web Store

Работает в Chrome, Edge, Brave, Opera · Без аккаунта · Бесплатно

// как это работает

Три шага

  1. Установите CodeRa из Chrome Web Store.
  2. Откройте урок на YouTube, Udemy или Coursera.
  3. Нажмите захват кадра (или Alt+C) — код попадёт в буфер обмена.

Когда нужен CodeRa

  • Нужно скопировать код с видео, а не перепечатывать вручную
  • Важно сохранить отступы Python, JS, React и других языков
  • Хотите распознать код со скриншота или слайда без пяти шагов в ChatGPT

Частые вопросы

Это бесплатно?

Да, в раннем доступе все функции открыты. Аккаунт и карта не нужны.

Безопасно ли для работы?

CodeRa ничего не хранит на своих серверах. Изображения обрабатываются API Anthropic по их политике. Перед отправкой чувствительного кода ознакомьтесь с ней. Подробнее: Privacy.

Чем отличается от Google Lens?

Lens — общий OCR. CodeRa заточен под код и захват кадра обучающего видео в браузере. Сравнение: CodeRa vs Google Lens.
