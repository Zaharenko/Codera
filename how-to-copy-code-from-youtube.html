How to copy code from a YouTube video

By Anton Zakharenka · Published 7 Oct 2026 · Updated 8 Oct 2026

Short answer: YouTube has no copy button for code shown inside a video, but there are four ways to get it out: retype it, run OCR such as Google Lens, upload a screenshot to a chatbot, or use a Chrome extension like CodeRa that captures the frame and extracts formatted code in one click. The right choice depends on how much code there is and whether it may leave your device.

Note that captions and the transcript contain speech, not the code on screen.

Method 1 — Retype by hand

Pause, zoom, type. It works offline and nothing leaves your machine. Fine for a few lines and painful for a 20-minute React lesson.

Method 2 — OCR with Google Lens or system text recognition

  1. Pause on a clean frame and take a screenshot of the code.
  2. Open it in Google Lens, or use Live Text on macOS and iOS.
  3. Copy the recognized text.
  4. Fix indentation and misread symbols by hand.

General OCR is built for signs and documents, not source code. See CodeRa vs Google Lens.

Method 3 — Screenshot to a chatbot

  1. Screenshot the code and save or copy the image.
  2. Open ChatGPT or Claude and attach the image.
  3. Prompt: “Extract the code from this image exactly. Preserve indentation and line breaks. Return only one code block.”
  4. Copy the result.

It can be accurate, but it takes several steps and sends the image to that service.

Method 4 — CodeRa in your browser

  1. Install CodeRa from the Chrome Web Store.
  2. Open the tutorial on YouTube.
  3. Press Alt+C or click the floating CodeRa button. The video keeps playing.
  4. Choose Extract as code (or plain text, or understand).
  5. Paste into your editor with Ctrl+V.

Collect a whole lesson (1.2.0, rolling out). Start collection and keep watching. CodeRa samples frames as you play, then builds a timestamped timeline and assembled files. Many frames are sent for processing while collection is on.

Why code OCR fails (and what to look for)

  • Flattened indentation — the recognizer sees text lines, not code structure.
  • Font ligatures (Fira Code / JetBrains Mono): =>, !==, -> as single glyphs.
  • Look-alike characters: l, 1 and I, or 0 and O.
  • Line numbers glued to code.
  • Low-contrast syntax colors and compression blur.
  • Code that scrolls — one frame never shows the whole function.

Tips for cleaner results

  • Pause or scrub to a frame without the mouse cursor or a popup over the code.
  • Use theater or full-screen mode; quality 1080p or higher.
  • Select only the code area.
  • Turn on visible whitespace in your editor.
  • Run a linter or compile quickly.
  • Check the video description for a GitHub repository first.

Troubleshooting

  • Black or empty frame: the player blocks capture — use the author’s resources.
  • Garbled symbols: zoom the player, pick a sharper frame, retry.
  • Missing lines: the code scrolled — capture again or use lesson collection.
  • Wrong indentation: compare against the video and check tab settings.

FAQ

Can I copy code from a YouTube video without retyping?
Yes: with OCR, a chatbot, or an extension like CodeRa that reads the on-screen frame.

Is this the same as YouTube captions?
No. Captions are speech. Code tools read the pixels of the editor on screen.

Does it work on live streams?
Yes, as long as the frame is readable. The video does not need to be paused.

Is my video sent anywhere?
Only the frame you capture is sent, through the CodeRa relay to Anthropic’s API. See Privacy.
